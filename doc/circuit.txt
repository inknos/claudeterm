1. Introduction                                   *circuit-introduction*

vim-circuit embeds OpenCode (https://github.com/opencode-ai/opencode)
in Vim using the built-in |:terminal| feature. It manages a persistent
terminal session tied to your current project and provides commands for
session management, model selection, plan workflow, and more.

Key design principles:

  - Single persistent terminal per project (no spawning duplicates)
  - Toggle show/hide without losing session state
  - Every command reachable three ways: long form, short alias, keymap
  - Every keymap and behavior configurable via |g:circuit_*| variables
  - Lifecycle hooks via |User| autocommands for extensibility
  - Server API integration for reliable prompt delivery

==============================================================================
2. Requirements                                   *circuit-requirements*

  - Vim 8.0+ compiled with |+terminal|
  - OpenCode (`opencode`) installed and in $PATH
  - The CLI must be authenticated and functional on its own
  - Git

After installing, run: >

4. Quick Start                                     *circuit-quickstart*

Open an OpenCode terminal:                         *:CTerm* *:CT*
>
  :CTerm
  " or press <leader>c
<
The session persists -- toggling hides and restores the same terminal.

Resume an older session interactively:             *:CTerm-resume*
>
  :CTerm resume
<
Switch model:                                      *:CTerm-model*
>
  :CTerm model {name}
<
Enter plan mode:                                   *:CTerm-mode*
>
  :CTerm mode plan
<
Use |<leader>[| to open the command prompt for quick access to all
commands.

5. Commands                                         *circuit-commands*

All commands support the dispatcher form `:CTerm {subcommand}` and short
aliases. Tab-completion is available for all subcommands and their
arguments.

------------------------------------------------------------------------------
5.1 Session Management                                *circuit-session*

                                                      *:CTerm-toggle*
:CTerm                  Toggle the OpenCode terminal. Resumes the most
:CT                     recent session (`--continue`), or starts a new one
                        if none exists. Shows/hides if a session is already
                        running.

                                                      *:CTresume*
:CTerm resume           Open the session list (`opencode session list`).
:CTresume               Kills the current terminal first if one is running.

                                                      *:CTcontinue*
:CTerm continue         Resume the most recent conversation in the current
:CTcontinue             directory.

                                                      *:CTnew*
:CTerm new              Kill the current session and start a brand new one.
:CTnew

                                                      *:CTkill*
:CTerm kill             Kill the terminal buffer entirely.
:CTkill

------------------------------------------------------------------------------
5.2 Mode Control                                       *circuit-modes*

Send slash commands to switch interactive modes in the running session.
If no session is running, one is opened first.

                                                      *:CTplan*
:CTerm plan             Enter plan mode (sends `/plan`).
:CTplan

:CTerm mode {mode}      Send `/{mode}` to the running session
                        (tab-completable).

------------------------------------------------------------------------------
5.3 Window Control                                    *circuit-window*

                                                      *:CTerm-position*
:CTerm position {pos}   Move the terminal to a different split position.
                        {pos} is one of: `right`, `left`, `top`, `bottom`.

------------------------------------------------------------------------------
5.4 Code Context                                     *circuit-context*

                                                      *:CTsend*
:CTerm send             Send the current visual selection to the OpenCode
:CTsend                 terminal. The text is prefixed with the filename.
:[range]CTsend           As |:CTsend| with a line range: sends those lines.
                        (Accepts a range so you can use `:'<,'>CTsend` after
                        a visual selection without |E841|.)

                                                      *:CTchat*
:CTerm chat             Prompt for a free-form message and send it to the
:CTchat                 agent. Opens the terminal if not visible.

                                                      *:CTref*
:[range]CTref           Append a line reference to the staged refs list. The
                        string is `relpath:line` for one line, or
                        `relpath:first-last` (path relative to the git root
                        when |g:circuit_use_git_root| is `1`, else relative
                        to the current working directory), e.g. `src/x.py:3`
                        or `src/x.py:10-20`. Multiple refs can be staged
                        before sending. Refs are not sent until you use
                        |:CTrefsend| or |<C-l>| in the agent |terminal| (see
                        |g:circuit_tmap_c_l_sends_staged|). With no range, the
                        current line is used (same for |:CTerm| |ref|).

                                                      *:CTaddtochat*
:CTaddtochat            Same as |:CTref| (mnemonic: add a reference to the
                        agent chat). Accepts a |:range| like |:CTref|.

:CTerm ref              Stages a reference for the cursor line (no range
                        in this form). For a range, use a ranged |:CTref| or
                        |:CTaddtochat| instead.

                                                      *:CTrefsend*
:CTerm refsend          Send all staged refs to the running agent terminal
:CTrefsend              (one per line), then clear the list. Shows the
                        terminal if hidden and focuses it (enters terminal
                        mode). Same as a successful |<C-l>| in |terminal|
                        mode when refs are pending. When
                        |g:circuit_refsend_switch_tab| is `1`, also
                        switches to the tab containing the terminal.
:[range]CTrefsend        Ignores the range; accepts one so
                        `:'<,'>CTrefsend` does not raise |E841| after
                        a visual selection.

                                                      *:CTrefclear*
:CTerm refclear         Clear all staged refs without sending them.
:CTrefclear

                                                      *:CTreflist*
:CTerm reflist          Show all currently staged refs as a numbered list.
:CTreflist

5.10 Plan Workflow                              *circuit-plan-workflow*

The plan workflow lets you review and edit the agent's plan in a
normal Vim buffer before executing it. OpenCode writes plans to
`<project>/.opencode/plans/`; vim-circuit opens the most recent one
in the current window for editing.

Typical session: >
  :CTplan                " CLI enters plan mode
  " (give the agent a task in the terminal)
  " (agent produces a plan, writes it to disk)
  :CTplanopen            " plan file opens in the current window
  " (review, edit, or refine via the agent)
  :CTplanexec            " send plan for execution
<

                                                      *:CTplanopen*
:CTerm planopen         Open the most recent plan file from
:CTplanopen             `.opencode/plans/` in the current window. Sets
                        |'autoread'| on the buffer. If already open
                        in a window, focuses it.

                                                      *:CTplanexec*
:CTerm planexec         Read the plan buffer and send its contents to the
:CTplanexec             OpenCode terminal as a prompt. Closes the plan
                        buffer afterward unless
                        |g:circuit_plan_close_on_exec| is `0`.

                                                      *:CTplanclose*
:CTerm planclose        Close the plan buffer window and restore the
:CTplanclose            previous window layout. Does not delete the file;
                        reopen with |:CTplanopen|.

5.11 Command Prompt                                  *circuit-prompt*

                                                      *:CTprompt*
:CTerm prompt           Open a floating command palette. Type to filter
:CTprompt               subcommands, use |<Tab>|/|<S-Tab>| to navigate,
                        |<CR>| to execute, |<Esc>| to cancel.

                        Subcommands that require an argument (`mode`,
                        `model`, `position`) chain a second popup with
                        context-aware completions.

                        Fuzzy matching: candidates are filtered and ranked
                        by match quality. Matched characters are
                        highlighted in the popup. On Vim 8.2.1726+ the
                        built-in |matchfuzzypos()| provides scored ranking
                        and multi-word matching (e.g. "pl op" matches
                        "planopen"). On older Vim versions a case-
                        insensitive subsequence filter is used instead
                        (matching but no score-based ranking).

                        Requires Vim with |+popupwin| (8.2+). Falls back
                        to |input()| with tab-completion when popups are
                        not available.

------------------------------------------------------------------------------
5.12 Server                                            *circuit-server*

The plugin automatically manages
a background `opencode serve` process per Vim instance. The server is
started lazily on the first command that needs it (or at VimEnter when
|g:circuit_server_mode| is `'start'`) and killed on VimLeave.

The TUI terminal attaches to the managed server via `opencode attach`,
and commands like |:CTundo|, |:CTchat|, |:CTsend|, and |:CTrefsend|
use the server HTTP API instead of typing into the terminal.

                                                      *:CTping*
:CTerm ping             Ensure the server is running, then hit
:CTping                 `GET /global/health`. Reports the server URL
                        on success.

                                                      *:CTserve*
:CTerm serve            Manually start the background server. Normally
:CTserve                not needed (the server starts lazily), but
                        useful when |g:circuit_server_mode| is `'manual'`.

                                                      *:CTpick*
:CTerm pick             Open the TUI session picker overlay via
:CTpick                 `POST /tui/open-sessions`. Requires the
                        terminal to be open.

                                                      *:CTmodels*
:CTerm models           Open the TUI model picker overlay via
:CTmodels               `POST /tui/open-models`. Requires the
                        terminal to be open.

6. Keymaps                                           *circuit-keymaps*

All keymaps are registered only if |g:circuit_map_keys| is 1 (default).
All other commands are accessible via the command prompt (|:CTprompt|)
or ex commands (|:CTerm|).

------------------------------------------------------------------------------
6.1 Normal Mode                                *circuit-keymaps-normal*

  Key              Command         Variable ~
  <leader>c        Toggle          |g:circuit_map_toggle|
  <leader>[        Command prompt  |g:circuit_map_prompt|

------------------------------------------------------------------------------
6.2 Visual Mode                              *circuit-keymaps-visual*

  Key              Action ~
  <C-l>            Stage the selected lines as a ref, send to the agent
                   terminal, and clear. Equivalent to |:CTref| + |:CTrefsend|
                   in one step. See |g:circuit_vmap_c_l_sends_ref|.

------------------------------------------------------------------------------
6.3 Terminal Mode                            *circuit-keymaps-terminal*

These keymaps are active when the cursor is inside any terminal buffer.

  Key              Action ~
  <M-h>            Navigate to window left
  <C-j>            Navigate to window below
  <C-k>            Navigate to window above
  <C-l>            If a ref is staged (see |:CTref|), send it to the TUI;
                   else navigate to window right. See
                   |g:circuit_tmap_c_l_sends_staged| to always use
                   window-right and send only via |:CTrefsend|.
  <C-v>            Paste from system clipboard

  |<C-h>| is not mapped to window-left by default: in many terminals it is
  the same as Ctrl+Backspace (^H), so mapping it would steal
  word-delete in the OpenCode TUI. To restore the old
  |<C-h>| behavior, set |g:circuit_tmap_ch_left| to `1`.

7. Tab-Completion                                  *circuit-completion*

`:CTerm` supports context-aware tab-completion:

  :CTerm <Tab>           Completes subcommands: `resume`, `continue`,
                         `new`, `kill`, `plan`, `mode`, `position`,
                         `send`, `chat`, `ref`, `refsend`, `refclear`,
                         `reflist`, `model`, `version`, `undo`, `redo`,
                         `export`, `stats`, `sessions`, `planopen`,
                         `planexec`, `planclose`, `prompt`, `ping`,
                         `serve`, `pick`, `models`.

  :CTerm mode <Tab>      Completes available modes: `plan`.

  :CTerm model <Tab>     Completes model names (empty by default; full
                         model names are always accepted).

  :CTerm position <Tab>  Completes: `right`, `left`, `top`, `bottom`.

8. Hooks                                               *circuit-hooks*

The plugin fires |User| autocommands with a `CT` prefix at various
lifecycle points. Hook into them in your |vimrc|:
>
  autocmd User CTOpen echo "OpenCode session started"
  autocmd User CTReload echohl WarningMsg
        \ | echo "Buffers reloaded" | echohl None
<

Available events:

  Event                   When fired ~
  CTOpen                  Terminal buffer created for the first time
  CTToggleShow            Terminal shown (unhidden)
  CTToggleHide            Terminal hidden
  CTKill                  Terminal killed
  CTTermExited            OpenCode process exited (split closed, buffer wiped)
  CTReload                One or more buffers auto-reloaded
  CTModeChange            Interactive mode changed
  CTSessionChange         Session switched (resume/continue/new)
  CTUndo                  Undo slash command sent
  CTRedo                  Redo slash command sent
  CTExport                Export slash command sent
  CTSessionList           Session list opened
  CTChatRefStaged         A |:CTref| / |:CTaddtochat| line range was staged
  CTChatRefSent           Staged refs were sent to the terminal (via
                          |:CTrefsend| or |<C-l>| in |terminal| mode)
  CTChatRefCleared        Staged refs cleared (via |:CTrefclear|)
  CTPlanOpen              Plan buffer opened (|:CTplanopen|)
  CTPlanExec              Plan sent for execution (|:CTplanexec|)
  CTPlanClose             Plan buffer closed (|:CTplanclose|)

9. Configuration                              *circuit-configuration*

All variables use the `g:circuit_` prefix. Buffer-local `b:circuit_*`
overrides take precedence over global values.

Set variables in your |vimrc| before the plugin loads, or at any time
(most take effect on the next command invocation).

------------------------------------------------------------------------------
9.1 Core                                       *circuit-config-core*

                                                *g:circuit_provider*
g:circuit_provider          String (default: `'opencode'`)
                            The active backend. Currently only `'opencode'`
                            is supported. Set to `''` to disable.

                                                *g:circuit_command*
g:circuit_command           String (default: `''`)
                            Override the CLI binary name or path. When
                            empty (default), `opencode` is used.

                                                *g:circuit_position*
g:circuit_position          String (default: `'right'`)
                            Window position: `'right'`, `'left'`, `'top'`,
                            `'bottom'`.

                                                *g:circuit_split_ratio*
g:circuit_split_ratio       Float (default: `0.5`)
                            Terminal size as a fraction of the screen.

                                                *g:circuit_enter_insert*
g:circuit_enter_insert      Number (default: `1`)
                            Auto-enter terminal (insert) mode when the
                            terminal window gains focus.

                                                *g:circuit_use_git_root*
g:circuit_use_git_root      Number (default: `1`)
                            Start OpenCode at the git repository root.

                                                *g:circuit_model*
g:circuit_model             String (default: `''`)
                            Default model override. Empty means CLI
                            default. Full model names are accepted.

                                                *g:circuit_extra_args*
g:circuit_extra_args        String (default: `''`)
                            Extra CLI arguments appended to every OpenCode
                            invocation.

                                                *g:circuit_server_mode*
g:circuit_server_mode      String (default: `'lazy'`)
                            Controls when the background `opencode serve`
                            process is started:
                            `'lazy'`   — start on first command that
                                         needs the server (default).
                            `'start'`  — start at |VimEnter|.
                            `'manual'` — never auto-start; use |:CTserve|
                                         or |:CTping| to start manually.
                            The server is always stopped on |VimLeave|.

                                                *g:circuit_plan_close_on_exec*
g:circuit_plan_close_on_exec
                            Number (default: `1`)
                            When `1`, |:CTplanexec| closes the plan
                            buffer after sending the plan. Set to `0`
                            to keep the plan buffer open.

------------------------------------------------------------------------------
9.2 Auto-Reload                               *circuit-config-reload*

                                                *g:circuit_auto_reload*
g:circuit_auto_reload       Number (default: `1`)
                            Enable buffer mtime auto-reload while the agent
                            terminal is active. The same timer (see
                            |g:circuit_reload_interval|) still runs when
                            this is `0` so the plugin can detect a finished
                            job and close the terminal split (see
                            |CTTermExited|). |'autoread'| and
                            |g:circuit_notify_reload| only apply when this
                            is `1`.

                                                *g:circuit_autoread_during_session*
g:circuit_autoread_during_session
                            Number (default: `0`)
                            Off by default: does not touch |'autoread'|,
                            so your |vimrc| and global |'autoread'| are
                            respected. When `1`, set the global |'autoread'|
                            the first time an OpenCode terminal is
                            started in this Vim (|:CT| / |:CTerm|,
                            |:CTnew|, etc.), and restore
                            the previous |'autoread'| value when that
                            session ends (|:CTkill|, the OpenCode process
                            exits, or you replace the terminal, e.g.
                            |:CTnew|, |:CTcontinue|). Use when
                            |'autoread'| is off in your |vimrc| but you
                            want auto-reload only while a session is
                            open. |b:circuit_autoread_during_session|
                            overrides the global in the buffer if set.

                                                *g:circuit_reload_interval*
g:circuit_reload_interval   Number (default: `1000`)
                            Polling interval in milliseconds for the
                            timer that checks for a finished job and, when
                            |g:circuit_auto_reload| is on, for buffer
                            mtime changes.

                                                *g:circuit_notify_reload*
g:circuit_notify_reload     Number (default: `1`)
                            Echo a notification when buffers are reloaded.

                                                *g:circuit_checktime_on_bufenter*
g:circuit_checktime_on_bufenter
                            Number (default: `1`)
                            When `1` and |g:circuit_auto_reload| is on, run
                            |:checktime| on |FocusGained| and |BufEnter|. Set
                            to `0` to use only the timer for mtime reloads, if
                            focus/buffer events cause unwanted redraws or
                            cursor flicker while a |:terminal| (e.g. the agent
                            TUI) is open in a split.

------------------------------------------------------------------------------
9.3 Keymaps                                  *circuit-config-keymaps*

                                                *g:circuit_map_keys*
g:circuit_map_keys          Number (default: `1`)
                            Set to `0` to disable all default keymaps.

                                                *g:circuit_map_toggle*
g:circuit_map_toggle        String (default: `'<leader>c'`)
                            Keymap for |:CT| (toggle terminal).

                                                *g:circuit_map_prompt*
g:circuit_map_prompt        String (default: `'<leader>['`)
                            Keymap for |:CTprompt| (floating command
                            palette). All other commands are
                            accessible through the prompt.

Example override: >
  let g:circuit_map_toggle = '<F5>'
  let g:circuit_map_prompt = '<leader>p'
<

                                                *g:circuit_tmap_ch_left*
g:circuit_tmap_ch_left      Number (default: `0`)
                            When `1` and |g:circuit_map_keys| is on,
                            map |<C-h>| in terminal mode to "window
                            left" (same as |<M-h>|). Default is `0`
                            because |<C-h>| matches Ctrl+Backspace in
                            many terminals and breaks line editing in
                            some agent CLIs.

                                                *g:circuit_tmap_c_l_sends_staged*
g:circuit_tmap_c_l_sends_staged
                            Number (default: `1`)
                            When `1` and |g:circuit_map_keys| is on, |<C-l>|
                            in the agent |terminal| sends a staged
                            `relpath:line` or `relpath:first-last` (see
                            |:CTref|) if one is
                            pending; otherwise it runs |<C-w>|l. Set to `0`
                            to always use |<C-w>|l and add references only
                            with |:CTrefsend| (e.g. if the OpenCode TUI
                            needs raw |<C-l>|).

                                                *g:circuit_vmap_c_l_sends_ref*
g:circuit_vmap_c_l_sends_ref
                            Number (default: `1`)
                            When `1` and |g:circuit_map_keys| is on, |<C-l>|
                            in |Visual| line mode stages the selected lines
                            as a ref and sends it to the agent terminal in
                            one step (|:CTref| + |:CTrefsend|). Set to `0`
                            to disable.

9.5 Session Control                      *circuit-config-session-control*

These variables control whether commands auto-start a terminal session
and whether they reveal a hidden terminal split.

                                                *g:circuit_start_on*
g:circuit_start_on          Number (default: `1`)
                            Global default for auto-starting a session.
                            When `1`, commands like |:CTrefsend|, |:CTsend|,
                            |:CTchat|, and |:CTplan| auto-start a new
                            terminal session when none is active. When `0`,
                            they print an error and do nothing.

                                                *g:circuit_show_on*
g:circuit_show_on           Number (default: `1`)
                            Global default for revealing a hidden terminal.
                            When `1`, the above commands open the terminal
                            split if it is alive but hidden. When `0`, they
                            send to the terminal buffer silently (no split,
                            no focus change).

Per-command overrides (unset by default; when defined, they take
precedence over the global setting for that command):

                                          *g:circuit_start_on_refsend*
g:circuit_start_on_refsend  Number (default: unset, falls back to
                            |g:circuit_start_on|)
                            Override auto-start for |:CTrefsend|.

                                          *g:circuit_show_on_refsend*
g:circuit_show_on_refsend   Number (default: unset, falls back to
                            |g:circuit_show_on|)
                            Override reveal-on-send for |:CTrefsend|.

                                          *g:circuit_refsend_switch_tab*
g:circuit_refsend_switch_tab
                            Number (default: `0`)
                            When `1`, |:CTrefsend| switches to the tab
                            containing the agent terminal after sending
                            the staged refs. Useful when you keep the
                            agent in a separate tab and edit code in
                            another. When `0` (the default), only focuses
                            the terminal if it is visible in the current
                            tab.

                                          *g:circuit_start_on_send*
g:circuit_start_on_send     Number (default: unset, falls back to
                            |g:circuit_start_on|)
                            Override auto-start for |:CTsend|.

                                          *g:circuit_show_on_send*
g:circuit_show_on_send      Number (default: unset, falls back to
                            |g:circuit_show_on|)
                            Override reveal-on-send for |:CTsend|.

                                          *g:circuit_start_on_chat*
g:circuit_start_on_chat     Number (default: unset, falls back to
                            |g:circuit_start_on|)
                            Override auto-start for |:CTchat|.

                                          *g:circuit_show_on_chat*
g:circuit_show_on_chat      Number (default: unset, falls back to
                            |g:circuit_show_on|)
                            Override reveal-on-send for |:CTchat|.

                                          *g:circuit_start_on_mode*
g:circuit_start_on_mode     Number (default: unset, falls back to
                            |g:circuit_start_on|)
                            Override auto-start for |:CTplan|.

                                          *g:circuit_show_on_mode*
g:circuit_show_on_mode      Number (default: unset, falls back to
                            |g:circuit_show_on|)
                            Override reveal-on-send for |:CTplan|.

                                                *g:circuit_sendkeys_delay*
g:circuit_sendkeys_delay    Number (default: `200`)
                            Milliseconds to wait before sending keys to a
                            freshly started terminal. When |g:circuit_start_on|
                            auto-starts a session, the agent CLI needs time
                            to initialize before it can accept input. Increase
                            this value if keys are lost on slow machines.
                            Set to `0` to send immediately (not recommended).

Resolution order (first defined wins): >
  b:circuit_start_on_refsend
  g:circuit_start_on_refsend
  g:circuit_start_on
  1 (hardcoded default)
<

Summary table: ~

  Command          start_on override           show_on override ~
  |:CTrefsend|       g:circuit_start_on_refsend   g:circuit_show_on_refsend
  |:CTsend|          g:circuit_start_on_send       g:circuit_show_on_send
  |:CTchat|          g:circuit_start_on_chat       g:circuit_show_on_chat
  |:CTplan|          g:circuit_start_on_mode       g:circuit_show_on_mode

  Global defaults: |g:circuit_start_on| (1)    |g:circuit_show_on| (1)

  start_on = 1     Command auto-starts a new session when none is active.
  start_on = 0     Command prints an error and does nothing.
  show_on  = 1     Command reveals a hidden terminal split and focuses it.
  show_on  = 0     Command sends to the terminal buffer silently (no
                   split, no focus change).

Commands not listed here are unaffected:
  - Session starters (|:CT|, |:CTresume|, |:CTnew|, etc.) always open
    a visible terminal.
  - Silent commands (|:CTundo|, |:CTredo|, |:CTref|, etc.) never reveal
    the split.

Example configurations: >
  " Default: every command starts and shows (the "just works" setup)
  let g:circuit_start_on = 1
  let g:circuit_show_on  = 1

  " Silent mode: commands auto-start but never pop open the split
  let g:circuit_start_on = 1
  let g:circuit_show_on  = 0

  " Selective: only :CTchat auto-starts; others bail
  let g:circuit_start_on = 0
  let g:circuit_start_on_chat = 1
<

10. Troubleshooting                          *circuit-troubleshooting*

Terminal does not open~
  Verify `vim --version | grep +terminal`. This plugin requires Vim
  compiled with +terminal.

OpenCode not found~
  Ensure `opencode` is in `$PATH` and working. Run `opencode --version`
  in a shell to verify.

Buffers not reloading~
  Check that `g:circuit_auto_reload` is `1` and that |'autoread'| is
  not globally disabled.

`:qa` reports "Job still running"~
  This should not happen: the plugin registers a |QuitPre| autocommand
  that kills the circuit terminal before Vim quits. If you see `E947`
  anyway, the terminal buffer may belong to a different plugin. Use
  `:qa!` to force quit.

Empty window after OpenCode exits~
  When the OpenCode process exits, the split should close
  automatically (|TermClose| or the circuit timer). If a stale buffer
  remains, run |:CTkill| or `:bwipe` that buffer.

OpenCode prints JSON (`sessionID`, `invalid_format`, `ses`, etc.)~
  This comes from the `opencode` process, not from vim-circuit. The
  plugin only runs the shell command (e.g. `opencode --continue` for
  |:CT|). Some OpenCode versions or features (e.g. subagent dispatch)
  validate session IDs and may log a JSON error if a placeholder such
  as `dummy` is used where a real ID (starting with `ses`) is
  required. Workarounds: upgrade `opencode` to the latest release, try
  |:CTnew| to start without `--continue`, and check OpenCode
  project issues for the exact message. If the session still works,
  the line is often harmless noise from a background request.

Keymaps conflict~
  Set `g:circuit_map_keys = 0` to disable all defaults, then define
  your own mappings.

Ctrl+Backspace in the agent TUI jumps to another window~
  Many terminals send the same `^H` for Ctrl+Backspace and for
  |<C-h>|. The default maps |<M-h>| to "window left" in |terminal| mode
  (not |<C-h>|). See |g:circuit_tmap_ch_left| if you need the old
  |<C-h>| window-left mapping.

Cursor flickers in the text window while the agent runs~
  A busy |:terminal| in a split often forces full-screen redraws; Vim
  cannot always isolate updates to the terminal window. The plugin
  also runs a timer (see |g:circuit_reload_interval|) and optional
  |:checktime| on focus/buffer change (|g:circuit_checktime_on_bufenter|);
  these can add minor redraws. Try, in your |vimrc|:
  `set lazyredraw`, or `let g:circuit_checktime_on_bufenter = 0`, or
  `let g:circuit_notify_reload = 0` (or `g:circuit_auto_reload = 0` if
  you can live without auto-reload while a session is open; exit
  detection in the same timer still runs), or a longer
  |g:circuit_reload_interval|.
